One original one-line joke about office life, 126 characters, written to be judged head to head by make.fun's AI judge.

> Our daily standup takes fifteen minutes: ten to find the meeting link, four to say 'you're on mute', one to actually stand up.

Built for the [make.fun "Make the AI Judge Laugh: Office Jokes" bounty](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a), $5 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) checks the line is a single line of 1 to 199 characters and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), so both runs write the same bytes. No network, nothing else read or written.
